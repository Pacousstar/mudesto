Gestion des membres

Ajoutez, modifiez ou supprimez les membres (photos, cotisations...). Puis cliquez sur « Publier sur GitHub » : le site public est mis à jour automatiquement en 1-2 minutes.

Attention : cette page fonctionne en local (aucune donnée ne part sur internet). Après export, remplacez le fichier site/data/data.js puis republiez le site (voir README.md). Les membres marqués « EXEMPLE » sont à remplacer par les vrais.
💾 Modifications non enregistrées — cliquez sur « Publier sur GitHub » pour les mettre en ligne (sinon elles seront perdues).
Mise à jour automatique : après vos modifications, cliquez sur « Publier sur GitHub » ci-dessous. Le site pacousstar.github.io/mudesto sera à jour en 1-2 minutes, sans rien télécharger.
Comment créer le jeton GitHub (2 minutes, à faire une seule fois)
  1. Ouvrez github.com/settings/tokens?type=beta (connecté en Pacousstar)
  2. Cliquez Generate new token → nommez-le mudesto-admin
  3. Durée : No expiration (ou une durée à votre choix)
  4. Dans Repository access : choisissez Only select repositories → sélectionnez mudesto
  5. Dans Permissions → Contents → choisissez Read and write
  6. Cliquez Generate token puis copiez le jeton (affiché une seule fois)
  7. Collez-le dans le champ ci-dessus puis cliquez Publier sur GitHub

Le jeton est enregistré uniquement dans votre navigateur (aucun serveur) et limité au seul dépôt mudesto.
